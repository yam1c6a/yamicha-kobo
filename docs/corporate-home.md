# トップページ

やみちゃ工房のトップページでは、AIエージェント開発・業務システム開発・地図データの活用について、相談内容と関連する実績を紹介します。白・紺・シアンを基本に、情報の役割に合わせて面積と配置に強弱をつけています。

## デザイン

- ヒーローは白い説明エリアと淡いブルーの図解エリアに分けます。`HeroWorkflow.astro` の図は「情報の参照 → 処理 → 人による確認 → 業務への活用」を表す説明用の図であり、実製品の画面や無人運転の保証ではありません。「活用イメージ」の表示と読み上げ用の説明を付けます。
- サービスは3列を基本とし、枠で囲まずにアイコン・見出し・区切り線で整理します。スマートフォンでは1列にします。
- 実績は代表1件を大きく、続く2件を2列に配置します。狭い画面では順序を変えずに1列へ切り替えます。3件の図解は既存の `ProjectDiagram.astro` / SVG を使い、「説明用イメージ」の表示を維持します。
- 主要な説明文は1remを基本にします。色やサイズだけでなく余白、整列、セクションごとの密度で読み順を示します。
- ロゴと基本の配色を維持します。トップページのテーマは `.corporate-site` 内だけに適用し、製品ページやプライバシーページのスタイルを変更しません。

## 維持する情報と機能

- 実績の正本は `src/data/case-studies.js` です。「すべての開発実績を見る」から8件の用途・目的、主な機能、設計・実装、システム構成を確認できます。既存の `#case-*` から各案件を直接開けます。
- 守秘義務の注意書き、説明用図解の表示、税務上の最終判断は税理士が行うという境界を維持します。実績・数値・顧客の声は追加していません。
- 問い合わせ先は `contact@yamicha.com` です。AI相談室は `#consult` にあり、既存の `/api/chat` を使います。ヒーローとモバイルメニューにも入口を設けます。
- スキップリンク、キーボードフォーカス、モバイルメニューのEscape・外側クリック・リンク選択時の閉鎖、折りたたみ欄、既存のURLハッシュを維持します。

## 検証

```sh
npm ci
node --test tests/*.test.mjs
npm run build
node scripts/verify-home.mjs
```

GitHub Actionsも同じ順で実行します。生成HTMLのアンカー、ID、図解、実績、メールリンク、AI相談フォームを検証します。実際のモデルへの送信にはCloudflareのバインディングが必要です。

表示は `npm run preview` で起動して確認します。320・390・768・920・1440pxの幅で、横はみ出し、文字の改行、図解、実績の1+2配置と縦積みを確認します。メニュー、実績への直接リンクと開閉欄、メールリンク、AI相談室への移動も確認します。静的プレビューではAIを実送信せず、UIの確認と実モデルの検証を区別します。

`main` へのpushは本番公開につながります。デザイン変更は別ブランチとプルリクエストで確認してから反映します。
