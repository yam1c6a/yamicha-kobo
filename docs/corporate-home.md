# トップページ

やみちゃ工房のトップページでは、業務システム開発・AIエージェント開発・地理空間システムを独立した開発領域として紹介します。白・紺・シアンを基本に、情報の役割に合わせて面積と配置に強弱をつけます。

## 2026-11-14のレビュー修正

ユーザーから「AIっぽい」「地図までAIエージェントに入れるのは違う」と指摘がありました。地図情報をAIエージェントへの入力として接続するトップ図解は、事業の関係を誤って表現していたため撤回します。

- `HeroWorkflow.astro`を削除し、`BusinessHero.astro`に置き換えます。トップでは疑似ウィンドウ、処理フロー、接続線、淡い背景の角丸図解を使いません。
- 主見出しは事業全体を示す「システム開発で、業務の課題を解決。」とします。AIは提供する開発領域の一つであり、地理空間開発の上位概念ではありません。
- 白い見出し・説明エリアの下に紺色の事業案内を配置します。業務システム開発、AIエージェント開発、地理空間システムを同じ階層の3リンクとして並べ、各相談内容へ移動します。
- 地理空間の案内はGIS・地図ビューア・道路データとし、AIが必須・内部に含まれるという説明を加えません。
- スマートフォンでは3つの事業案内を同じ順序で縦に並べます。矢印はリンク先への移動を示すもので、事業間の処理フローではありません。

## ページ下部と維持する機能

- サービスは3列を基本とし、スマートフォンでは1列にします。
- 実績は代表1件を大きく、続く2件を2列に配置します。狭い画面では順序を変えずに1列へ切り替えます。3件の個別実績の図解は既存の `ProjectDiagram.astro` / SVGを使い、「説明用イメージ」の表示を維持します。トップの事業構成図とは区別します。
- 実績の正本は `src/data/case-studies.js` です。8件の用途・目的、主な機能、設計・実装、システム構成と既存の `#case-*` を維持します。
- 守秘義務の注意書き、税務上の最終判断は税理士が行うという境界を維持します。実績・数値・顧客の声は追加しません。
- 問い合わせ先は `contact@yamicha.com` です。AI相談室は `#consult` にあり、既存の `/api/chat` を使います。モバイルメニュー、フッター、お問い合わせ欄から案内します。
- ロゴ、主要本文1rem、スキップリンク、フォーカス、メニューのEscape・外側クリック・リンク選択時の閉鎖、折りたたみ欄を維持します。
- ホーム専用の変更とし、製品・プライバシーページ、共通CSS、実績データ、AI処理、依存関係は変更しません。

## 検証

```sh
npm ci
node --test tests/*.test.mjs
npm run build
node scripts/verify-home.mjs
```

生成HTMLについて、単一の主見出し、3領域の並列リスト・各アンカー、誤ったトップ図解が戻っていないこと、8実績・図解表示・メール・AI相談フォームを検証します。

表示は320・390・768・920・1440pxで確認します。横はみ出し、見出しの改行、3領域の移動先、メニュー、実績の開閉、AI相談室の入力欄への移動を確認します。静的プレビューでAIを実送信せず、UIの確認と実モデルの検証を区別します。

`main`へのpushは本番公開につながるため、別ブランチとドラフトPRで確認し、承認前に本番反映しません。
