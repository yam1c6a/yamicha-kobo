# トップページ

やみちゃ工房のトップページでは、業務システム開発・AIエージェント開発・地理空間システムを独立した開発領域として紹介します。白・紺・シアンを基本に、情報の役割に合わせて面積と配置に強弱をつけます。

## レビューで確認した方針

ユーザーは岩崎電気・日清食品の配置や色使いを好み、元のトップの絵については「よかった」と評価しています。「01 02 03とかついてるのAIっぽい」という指摘に合わせ、順序を示す必要のないサービス欄の装飾用連番を削除します。元の素材まで一律に否定・交換するのではなく、配置・配色・読みやすさを改善します。

- `BusinessHero.astro`から、元の`ProjectDiagram.astro`の`variant="hero"`を再利用します。絵自体の内容・形・色は変更しません。業務フロー、AIエージェント、地図の3つのウィンドウが並ぶ元の絵です。
- 地図をAIエージェントへの入力として接続した前案の`HeroWorkflow.astro`は撤回したままです。元の絵の地図ウィンドウはAIウィンドウとは独立した要素であり、AIの内部にまとめません。
- 主見出しは事業全体を示す「システム開発で、業務の課題を解決。」とします。AIは提供する開発領域の一つであり、地理空間開発の上位概念ではありません。
- PCでは左に見出し・説明・問い合わせ、右に元の絵を配置します。スマートフォンでは説明の下に絵を置きます。大きな背景の追加や新たな説明図の制作はしません。
- 紺色の事業案内は、業務システム開発、AIエージェント開発、地理空間システムを同じ階層の3リンクとして維持します。地理空間の案内はGIS・地図ビューア・道路データです。
- サービス欄の「01・02・03」は非表示にするだけでなく、生成するHTMLから削除します。元の図の処理手順を表す数字や、実際に順序のある説明とは区別します。

## ページ下部と維持する機能

- サービスは3列を基本とし、スマートフォンでは1列にします。アイコン・見出し・説明で整理し、装飾用の連番を加えません。
- 実績は代表1件を大きく、続く2件を2列に配置します。狭い画面では順序を変えずに1列へ切り替えます。3件の個別実績の図解は既存の`ProjectDiagram.astro` / SVGを使い、「説明用イメージ」の表示を維持します。
- 実績の正本は`src/data/case-studies.js`です。8件の用途・目的、主な機能、設計・実装、システム構成と既存の`#case-*`を維持します。
- 守秘義務の注意書き、税務上の最終判断は税理士が行うという境界を維持します。実績・数値・顧客の声は追加しません。
- 問い合わせ先は`contact@yamicha.com`です。AI相談室は`#consult`にあり、既存の`/api/chat`を使います。モバイルメニュー、フッター、お問い合わせ欄から案内します。
- ロゴ、主要本文1rem、スキップリンク、フォーカス、メニューのEscape・外側クリック・リンク選択時の閉鎖、折りたたみ欄を維持します。
- ホーム専用の変更とし、製品・プライバシーページ、共通CSS、実績データ、AI処理、依存関係は変更しません。

## 検証

```sh
npm ci
node --test tests/*.test.mjs
npm run build
node scripts/verify-home.mjs
```

生成HTMLについて、単一の主見出し、3領域の並列リスト・各アンカー、元のトップ図解と活用イメージ表示、サービスの装飾連番の不在、誤ったAI接続図の不在、8実績・メール・AI相談フォームを検証します。

表示は320・390・768・920・1440pxで確認します。横はみ出し、見出しの改行、元の図の表示、3領域の移動先、メニュー、実績の開閉、AI相談室の入力欄への移動を確認します。静的プレビューでAIを実送信せず、UIの確認と実モデルの検証を区別します。

`main`へのpushは本番公開につながるため、別ブランチとドラフトPRで確認し、承認前に本番反映しません。
